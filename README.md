# EcoMetChem — сайт компании

Статический сайт: HTML + CSS + JS, без сборщиков и без сервера. Открывается прямо в браузере.

## Структура проекта

```
ecometchem/
├── index.html          вся разметка страницы
├── css/styles.css       стили и цветовая палитра (переменные в начале файла)
├── js/i18n.js            тексты на RU и EN + список материалов
├── js/script.js          логика: язык, мобильное меню, карточки материалов, форма
└── assets/logo.svg       логотип (векторный, перерисован по цветам оригинала)
```

## Как запустить локально

Вариант 1 — просто открой `index.html` двойным кликом. Сайт заработает, но лучше через локальный сервер (см. ниже), иначе в некоторых браузерах JS-файлы могут не подгружаться из-за ограничений безопасности при открытии файла напрямую (`file://`).

Вариант 2 — через VS Code:
1. Открой папку `ecometchem` в VS Code (`Файл → Открыть папку`)
2. Установи расширение **Live Server** (значок расширений слева, поиск "Live Server", Install)
3. Правой кнопкой на `index.html` → **Open with Live Server**
4. Сайт откроется в браузере на `http://127.0.0.1:5500` и будет обновляться при каждом сохранении

Вариант 3 — через терминал (раз у тебя уже установлен Node.js):
```
cd путь\до\папки\ecometchem
npx serve
```
Покажет ссылку типа `http://localhost:3000` — открой её в браузере.

## Как это работает

**Язык.** При первом заходе сайт смотрит язык браузера пользователя (`navigator.language`) — если русский, показывает RU, иначе EN. Кнопка переключения в шапке сохраняет выбор в `localStorage`, так что при следующем визите сайт помнит выбор пользователя. Логика — в `js/script.js`, раздел "1) LANGUAGE".

**Тексты.** Все тексты лежат в `js/i18n.js` в двух объектах — `en` и `ru`. Если нужно поправить формулировку — меняешь строку там, а не в `index.html`. В разметке вместо текста стоит `data-i18n="ключ"` — скрипт сам подставляет нужный перевод.

**Материалы (плитки-элементы).** Список материалов и их переводы — тоже в `js/i18n.js`, массив `MATERIALS`. Добавить новый материал — просто добавь новый объект в массив по образцу существующих.

**Форма обратной связи — важно.** Сейчас форма ничего никуда не отправляет, только показывает сообщение "демо-режим". Это статический сайт без сервера, отправлять письма ему не из чего. Два простых способа подключить реальную отправку без написания бэкенда:

- **Formspree** (https://formspree.io) — регистрируешься, получаешь ссылку вида `https://formspree.io/f/xxxxxxx`, добавляешь в `index.html` в тег `<form>` атрибут `action="твоя-ссылка"` и `method="POST"`, убираешь `id="contactForm"` (или просто убираешь `e.preventDefault()` в `script.js`). Бесплатного тарифа хватит для старта.
- **EmailJS** (https://www.emailjs.com) — чуть больше настройки, но письма приходят напрямую на почту без стороннего домена в адресе отправителя.

Могу подключить любой из вариантов в следующей сессии — просто скажи, какой выбираешь.

## Что нужно заменить перед запуском в бой

- `info@ecometchem.eu` в разделе контактов (`index.html`, секция `#contact`) — на реальную почту
- Регион/адрес — сейчас стоит заглушка "Europe-wide"
- Логотип — если у отца найдётся оригинальный векторный файл (.ai/.eps/.svg), просто заменишь `assets/logo.svg`

## Как выложить сайт в интернет (бесплатно)

Проще всего — **GitHub Pages**:
1. Создай репозиторий на GitHub
2. Залей туда содержимое папки `ecometchem` (через Git — см. ниже, или просто перетащи файлы в веб-интерфейсе GitHub)
3. В настройках репозитория → Pages → Source выбери ветку `main`
4. Через пару минут сайт будет доступен на `https://твой-логин.github.io/название-репозитория`

## Git — сохраняем историю с первого дня

```
cd путь\до\папки\ecometchem
git init
git add .
git commit -m "Первая версия сайта EcoMetChem"
```

Дальше при каждом изменении:
```
git add .
git commit -m "Что изменил"
```

Это создаёт локальную историю версий. Чтобы залить на GitHub — заведи там репозиторий и следуй подсказкам GitHub после его создания (`git remote add origin ...`, `git push`).
