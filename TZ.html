3. Вступительная заставка

Какой файл использовать

Использовать MP4. Исходник пользователя: H.264, 1920×1080, 30 кадров/с, 2,533 секунды, 1 363 779 байт. Переданный GIF — 960×540, но содержит один кадр, поэтому не является анимированной заменой видео.

В комплекте уже есть версия files/assets/fx/intro.mp4: 1280×720, H.264, yuv420p, без аудио, faststart. Размер около 340 КБ. Смысл, логотип и последовательность исходной анимации сохранены. Постер взят из момента 1,6 секунды, когда логотип виден. Это оптимизация предоставленного видео, не новая нарисованная заставка.

Правила показа

  • Один раз за сеанс вкладки: ключ sessionStorage.emc_intro_v2. Не показывать снова при reload в этой же вкладке и при переходе по якорям.
  • Не ждать загрузки всех видео, новостей, формы или офферов. Заставка — короткое вступление; индикатор выдуманного «процента загрузки» не нужен.
  • Пропускать при prefers-reduced-motion, Save-Data, соединении 2G, входе по прямому якорю или скрытой вкладке. При недоступном sessionStorage пропускать заставку.
  • muted, playsinline, без звука. Масштабирование contain, без обрезания логотипа. На узком экране допускаются поля вокруг видео.
  • Видимая кнопка «Пропустить» с переводами, Escape, Tab, завершение ролика, ошибка воспроизведения или уход во вкладку завершают заставку.
  • Предельное время активного оверлея — 2,9 секунды от начала показа, затем до 0,3 секунды плавного исчезновения. Если видео не успело загрузиться, сайт всё равно доступен. Не блокировать body через overflow:hidden.
  • Не выводить оверлей в исходном HTML. Он создаётся только успешно запущенным JS; при ошибке JS сайт остаётся доступным.

4. Анимированный логотип

Применить к .brand-logo-img и .footer-logo-img. Сохранить существующую ссылку логотипа, alt, занимаемое место и пропорции. Анимация пользователя — прозрачный WebP, 400×267, 40 кадров по 50 мс, цикл 2 секунды, около 609 КБ. Используется как предоставлена, без перерисовки букв и элементов бренда. Статичный fallback — извлечённый первый кадр той же анимации, чтобы переключение не меняло композицию.

Важная деталь: внутри <picture> тег <source> может переопределить img.src. Код удаляет только source у этих двух логотипов. Нельзя оставить старый srcset и ожидать, что смена img.src включит анимацию.

Анимированный WebP нельзя остановить через animation-play-state. Реальное отключение выполняется заменой src на статичный WebP. Нижний логотип анимируется только при видимости; верхний — пока он виден и вкладка активна. Reduced Motion и экономия данных используют статичный вариант. Свечение — небольшой drop-shadow, без яркого мигания и непрерывного изменения blur.

5. Визуальный язык фонов

Сохранить зелёно-голубую палитру бренда: зелёный #67bd71, голубой #489ecb, импульсы #55bddd, мягкий акцент #78cc84. Не вводить насыщенный фиолетовый, красный неон или радужные переливы.

Эффект глубины строится слоями: слабая сетка, основные дорожки, чуть более яркие короткие импульсы, узлы и маленькие площадки микросхем, два мягких пятна света. Текст и карточки остаются впереди и не движутся вместе с фоном. Ширина дорожки 1–1,5 SVG-единицы; непрозрачность сетки около 0,09, линий 0,14, импульсов 0,32–0,42. Заливки большие, но слабые: 0,065–0,08.

Техническая основа — один SVG на секцию плюс не более двух CSS-градиентов. У SVG viewBox="0 0 1200 500", для каждого импульса stroke-dasharray="28 1172", замкнутый сдвиг -1200 за 20–26 секунд. pathLength не нужен: рисунок импульса непрерывно проходит по маршруту. Никакого random-пересоздания фона каждый кадр.

Схема по секциям

  • Каталог: сохранить сетку. Добавить четыре маршрута под углами и прямые участки, контактные кольца, три небольших символа микросхем. Два импульса зелёного и два голубого оттенка.
  • Предложения/закупки: та же технологическая система, с маршрутом движения товара; не добавлять новые видео.
  • Услуги: вместо сетки сохранить кривые волны. Четыре кривые, на каждой проходит короткий импульс; общий слой медленно смещается на 10×8 пикселей, не двигая контент.
  • Преимущества: диагональные связи между узлами. Импульсы по связям и слабое изменение непрозрачности колец.
  • Новости: прямоугольные маршруты с короткими вертикальными переходами; иной ритм рисунка, чем у каталога.
  • Любая дополнительная секция с существующим не-видео фоном: подключать через data-emc-bg одним из этих типов. Не создавать новый раздел ради демонстрации эффекта.

Все декоративные контейнеры имеют aria-hidden="true", pointer-events:none, overflow:hidden, contain:paint. Секция создаёт свой stacking context через isolation:isolate, фон находится на z-index:-1. Не перекрывать чужие контейнеры, header или модальное окно.

Телефон и производительность

На экране до 700 px оставить две дорожки с движущимися импульсами, движение кривых в услугах и статичные базовые узлы. На каждой дорожке рисунок 18 382: несколько коротких сигналов, чтобы движение было видно и в узком фрагменте SVG. Скрыть детали .emc2-detail, дополнительные микросхемы, часть колец и второй световой слой. Цикл сдвига — 30 секунд, кривых — 34. Это сохраняет живой вид мобильной версии, не копируя всю нагрузку десктопа.

IntersectionObserver с точной видимостью включает движение только видимых секций. visibilitychange выключает его в неактивной вкладке. При Reduced Motion или экономии данных фон статичный. При отсутствии IntersectionObserver фон остаётся статичным, контент не скрывается.

SVG stroke-dashoffset может требовать перерисовки: его нельзя считать бесплатной compositor-анимацией. Поэтому ограничены число дорожек, толщина, количество одновременно видимых слоёв и мобильная детализация. Если измерения на бюджетном телефоне показывают рывки, сначала оставить один импульс на секцию, затем убрать движение волны. Не начинать с полного отключения мобильной версии.

6. Наведение, нажатие и 3D-эффект

Применять к реально кликабельным .element-tile, .dyn-list-item, .service-tile, a.btn, button.btn, .lang-current, .menu-toggle. Если в текущей версии .service-tile только декоративный div, удалить его из селектора, пока он не выполняет действие. Не ставить cursor:pointer на обычный текст или неактивную карточку.

  • Десктоп, fine pointer + hover: подъём 2 px, небольшая перспективная деформация с общей амплитудой 3° — от −1,5° до +1,5° по каждой оси, мягкая граница и тень. Подсветка следует за курсором только внутри карточки.
  • JS реагирует на pointermove, использует один requestAnimationFrame для объединения событий. Постоянного animation loop нет. Не применять will-change ко всем карточкам одновременно.
  • Динамически загруженные офферы и категории получают эффекты через делегирование событий и MutationObserver на пяти контейнерах. Новый код не заменяет существующие click-обработчики.
  • При выходе курсора, клавиатурном вводе, blur, смене pointer/reduced-motion — сбросить наклон.
  • Телефон: без симуляции курсора и без гироскопа. При касании — мягкий scale 0,987 и подсветка. Поддержать обычный tap, прокрутку и открытие карточки.
  • Для клавиатуры :focus-visible с контрастным outline. Не заменять его одной слабой тенью.

7. Кнопка «Актуализировать»

Точное место и UX

В /admin/ добавить ссылку «Актуализация офферов». Она открывает /admin/refresh.html — страницу внутри той же админки, со списком существующих предложений. У каждого — название, текущая дата, отметки hidden/pinned и кнопка «Актуализировать». Не требуется открывать сам оффер, редактировать поля или повторно загружать фото.

Это отдельный административный список, а не внедрение кнопки в приватную DOM-структуру стандартного списка Decap. Для текущего Decap нет основания рассчитывать на устойчивый публичный API кнопки строки; не писать хрупкий селектор к его внутренним классам. Существующий редактор Decap остаётся рабочим. Если нужен именно его стандартный список, сначала найти и проверить поддерживаемое расширение текущей установленной версии.

Логика сохранения

1. Авторизация через уже используемый netlify-identity-widget. Перед каждым запросом получить свежий currentUser().jwt().

2. Читать Git Gateway /.netlify/git/github/contents/content/offers?ref=main.

3. Показать список JSON-файлов content/offers/*.json, включая скрытые и закреплённые. Названия и ошибки отображать через textContent.

4. По кнопке заново читать конкретный файл с ref=main. Получить актуальные Base64-содержимое и SHA.

5. Изменить только верхнеуровневое поле date на текущий ISO timestamp (new Date().toISOString()). Все остальные байты сохраняются: отступы, title, description, photo, quantity, country, link, pinned, hidden и любые будущие поля. Вложенные поля с именем date не менять. Не создавать новый файл и не переименовывать существующий slug.

6. Выполнить PUT того же пути с branch: "main", актуальным sha, Base64-содержимым и понятным commit message.

7. До ответа заблокировать повторные кнопки. При 409/422 не перезаписывать конфликт автоматически: сообщить об изменении другим редактором и предложить обновить список. Тайм-аут сообщать без ложного утверждения, что сохранение точно не состоялось.

8. Успех: «Дата сохранена. На сайте обновится после успешной сборки Netlify». Сохранение в Git и обновление публичного сайта — разные события.

Часовой пояс бизнес-даты: Europe/Warsaw, с автоматическим учётом DST. В админке и formatEntryDate на сайте даты показываются в этом часовом поясе; данные остаются обычными ISO timestamps. Для определения «сегодня» применяется время устройства сотрудника — серверное доверенное время потребовало бы иной реализации. Не хранить секретный GitHub PAT в браузере, не создавать публичную функцию записи даты. Доступ проверяет существующий Git Gateway, а не просто скрытая кнопка.

В текущем проекте конфигурация уже backend.name: git-gateway, branch: main. Решение рассчитано на этот действующий backend; новую миграцию авторизации оно не выполняет. Перед публикацией обязательно проверить авторизацию и один тестовый оффер в реальном Netlify-окружении. При отключённом Git Gateway кнопка должна показывать ошибку, а не имитировать успешное сохранение.

12. Дополнительная идея после внедрения

Сначала оценить эту систему эффектов целиком. Если она выглядит убедительно, следующим аккуратным шагом может быть один переключатель «Уменьшить эффекты», который сохраняет выбор посетителя. Он полезен людям со слабым устройством даже без системной настройки Reduce Motion. В текущий пакет он намеренно не добавлен: не перегружать интерфейс новыми элементами до проверки основных изменений.

13. Источники по административному API

  • Netlify: Git Gateway — существующий backend проксирует API выбранного репозитория через /.netlify/git/github/.... В текущей документации сервис помечен deprecated, но работающие конфигурации продолжают функционировать; пакет использует уже существующую конфигурацию, не предлагает настраивать новый Git Gateway.
  • Netlify: исходный Git Gateway — JWT с достаточными правами и разрешённые endpoints, включая contents.
  • GitHub: repository contents API — GET содержимого и PUT обновления с Base64, SHA и branch.

 async function refresh(path,button,label){
  if(busy||loading||!validPath(path))return;busy=true;document.querySelectorAll('#offers button').forEach(b=>b.disabled=true);reload.disabled=true;msg('Сохраняем дату…');
  try{
   // Always re-read immediately before updating; SHA prevents overwriting concurrent edits.
   const file=await api(path);if(file.encoding!=='base64'||!file.sha)throw Error('Неожиданный формат файла.');
   const raw=decode(file.content);const offer=JSON.parse(raw);if(!offer||typeof offer!=='object'||Array.isArray(offer))throw Error('Некорректный JSON оффера.');
   const now=new Date().toISOString();
   // Change only the top-level date value; preserve original whitespace and every other key.
   const next=replaceDate(raw,now);
   await api(path,{method:'PUT',body:JSON.stringify({branch:BRANCH,sha:file.sha,message:'Refresh offer date: '+path.split('/').pop(),content:encode(next)})});
   label.textContent='Дата: '+date(now)+(offer.hidden?' · скрыто':'')+(offer.pinned?' · закреплено':'');msg('Дата сохранена. На сайте обновится после успешной сборки Netlify.');
  }catch(e){msg(e.name==='AbortError'?'Тайм-аут. Сохранение могло завершиться; обновите список перед повтором.':e.message);}
  finally{busy=false;document.querySelectorAll('#offers button').forEach(b=>b.disabled=false);reload.disabled=false;}
 }
 function replaceDate(raw,value){
  // JSON parsed first above. Track nesting and strings so nested "date" keys are untouched.
  let depth=0,string=false,escape=false,start=0;
  for(let i=0;i<raw.length;i++){
   const c=raw[i];if(string){if(escape){escape=false;continue;}if(c==='\\'){escape=true;continue;}if(c==='"'){string=false;
    if(depth===1&&raw.slice(start,i+1)==='"date"'){let a=i+1;while(/\s/.test(raw[a]||'')&&a<raw.length)a++;if(raw[a]!==':')continue;a++;while(/\s/.test(raw[a]||'')&&a<raw.length)a++;let b=a;if(raw[a]==='"'){b++;let esc=false;for(;b<raw.length;b++){if(esc){esc=false;continue;}if(raw[b]==='\\'){esc=true;continue;}if(raw[b]==='"'){b++;break;}}}else{while(b<raw.length&&!/[},]/.test(raw[b]))b++;while(b>a&&/\s/.test(raw[b-1]))b--;}
     const next=raw.slice(0,a)+JSON.stringify(value)+raw.slice(b);const before=JSON.parse(raw),after=JSON.parse(next);delete before.date;delete after.date;if(JSON.stringify(before)!==JSON.stringify(after))throw Error('Изменение затронуло другие поля.');return next;
    }
   }continue;}
   if(c==='"'){string=true;start=i;}else if(c==='{'||c==='[')depth++;else if(c==='}'||c===']')depth--;
  }
  throw Error('В оффере нет поля date. Исправьте его через обычный редактор.');
 }
