# Шпаргалка по сайту EkoMetChem (после финальной версии)

## Обычная работа
- **Добавить/изменить оффер, закупку, услугу:** ekometchem.com/admin → войти → нужная коллекция → сохранить. Через 1–2 минуты Netlify пересоберёт сайт сам.
- **Обновить дату оффера одной кнопкой:** ekometchem.com/admin/refresh.html → «Актуализировать» рядом с нужной позицией. Меняется только дата. Каждое нажатие = одна сборка Netlify (кредиты), поэтому жмите только на нужные.
- **Скрыть позицию:** в админке поставить «Скрыть» (hidden). На сайте она пропадёт после сборки.
- **Заявки:** ekometchem.com/admin/inbox.html и уведомления в Telegram.

## Если что-то пошло не так
- **Сайт не обновился после правки:** Netlify → Deploys. Красный деплой = в одном из файлов контента ошибка (сайт при этом остаётся на прошлой рабочей версии). Откройте лог деплоя: там написано, какой файл `content/...json` сломан.
- **В блоке офферов «Не удалось загрузить данные»:** нажмите «Повторить». Если не помогает, проверьте последний деплой в Netlify.
- **Раздел новостей пропал:** он скрывается, когда источники новостей не отвечают. Вернётся сам при следующей успешной загрузке (до 4 часов).
- **Откат:** Netlify → Deploys → выбрать предыдущий успешный деплой → «Publish deploy». Или в Git: `git revert <коммит>` и `git push`.

## Netlify: что можно почистить / включить
- Удалить переменную **METALS_DEV_API_KEY** (Project configuration → Environment variables): она больше не нужна.
- По желанию защита от чужих вызовов Telegram-функции: добавить переменную **TELEGRAM_WEBHOOK_SECRET** (любая длинная случайная строка) и в Forms → contact → Form notifications поменять адрес webhook на `https://ekometchem.com/.netlify/functions/telegram-notify?key=ТА_ЖЕ_СТРОКА`.

## Как устроен сайт теперь
- На каждой публикации скрипт `scripts/build-site.mjs` проверяет все файлы в `content/`, собирает один файл `content/index.json` и выкладывает на сайт только нужное (папка `dist`). Посетители больше не обращаются к GitHub.
- Шрифты лежат на нашем сервере (`assets/fonts`).
- Видео подгружаются только когда до них доскроллили; невидимые не играют.
